# How I read papers

**Principle:** Read to answer my questions, not to remember the paper. The literature matrix remembers for me.

## What to take by paper type
| Type | Take | Skip |
|---|---|---|
| Review | Main conclusion, 2–3 key numbers, named gaps | Search method, screening counts, long tables |
| Study | Question → data → method → main result → limitation | Equations, calibration steps |
| Methods | Steps, when to use | Maths |
| Data | Contents, resolution, access, limits | How the model was trained |

## 20-minute method
1. (2 min) Write my questions before opening
2. (3 min) Abstract
3. (3 min) Conclusion
4. (5 min) Figures, tables, headings
5. (5 min) Only sections answering my questions — use Ctrl+F ("gap", "limitation", "future", "Delhi", "arid")
6. (2 min) Close the paper; write the card from memory

Stop at 20–30 min. Deep-read only the 2–3 papers closest to my study.

## Paper card
```
Paper:
Why I read it:
Main takeaway (1 sentence):
Key numbers (max 3):
Gap / limitation:
How I'll use it in my project:   ← always ask "so what for Gurugram?"
```
